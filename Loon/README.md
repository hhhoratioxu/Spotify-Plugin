# SpotifyLyrics · Loon

本目录是 SpotifyLyrics 独立项目的 Loon 原生入口与开发工具。安装 [SpotifyLyrics.lpx](https://raw.githubusercontent.com/hhhoratioxu/SpotifyLyrics/main/Loon/script/SpotifyLyrics.lpx)，保持核心 3.2.2、原参数，运行脚本固定到新仓库完整提交。此次为迁移地址更新，功能验收结论保持。

手机默认 mobile；Mac 为 macOS。真实 Mac 无词补全仍未通过，iOS 50 MB 未验收。[安装与兼容说明](Docs/SpotifyLyrics.md)、[当前验收状态](../docs/acceptance.md)、[官方文档适配记录](Docs/OfficialReference.md)。迁移不操作安装中的 Loon 或 VPN。
