## 时间与恢复顺序

预计需要约10分钟**同时独占Mac UI和Loon**，包括恢复：约2分钟现场核验/备份，约4分钟导入与两首公开歌曲的静音观察，约3分钟移除临时项/比对恢复，约1分钟余量。服务600秒是上限，并非需要等满；收尾必须主动停止本轮服务。若前置备份/参数核验无法在窗口内完成，停止开测，报告缺口，不挤掉恢复时间或自行延长占用。

恢复先暂停本机播放，保存已许可的五字段事件，关闭/删除本次精确插件。仅移除确定新增且没有其他配置引用的独立缓存；比对两份配置、原插件、原缓存内容与索引。发现缺失仅使用本次T0备份；发现既存文件另有修改时保留它，停止自动覆盖并报告。不得用旧Map/Weather快照、全量旧配置或清空缓存来“恢复”。最后核对服务退出和VPN状态；不关闭/重启VPN，不改其他网络设置。

## 判定边界

预检通过说明文件、最小日志及保护条件的离线检查通过，**不等于实机可以直接开测**。旧 B 实测已结束；当前输入兼容新版本未部署，Weather 独占 UI / Loon，仍须等下一轮明确释放及新的当次 T0。已知 metadata / player / context JSON 可最小识别，未知 JSON 结构仍记unknown；publicTargetMatched 保持布尔值，false仅表示未确认，不是非目标证据。不得据此猜线上格式。真实无词补全、精确同步和iOS50MB均仍未验收。详见 [输入兼容记录](INPUT-COMPATIBILITY.md)。
