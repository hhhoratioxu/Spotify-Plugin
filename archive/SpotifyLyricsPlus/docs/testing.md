# 自动测试、证据与设备验收

核对日期：2026-11-13。所有新歌词夹具均为自写文字。网络来自显式模拟函数，测试不登录 Spotify、不请求真实歌曲歌词、不发送账号凭据。

`npm test` 和 `npm run test:baseline` 均可重现。`test-runtime/` 被忽略，不生成对应安装入口；其中有测试专用的来源白名单，不能上传或给客户端使用。`dist/` 按真实 `source-policy.json` 构建，测试同时确认其拒绝全部未核实来源。

## 场景覆盖

| --- | --- | --- |
| 原生有词 | 四语种、JSON/protobuf、静态/逐行原始字节、原生译文、未知字段保留，零附加请求 | 未验证 |
| 原生无词 | 模拟 404 及合法来源匹配，回写 JSON/protobuf | 未验证 |
| 网易云有 / QQ 无、QQ 有 / 网易云无、全无 | 自动来源顺序、顺序请求与失败保留、12 次上限 | 未验证 |
| 同名不同歌手、Live/Remix/翻唱 | 完整艺人核对、专辑、时长、明确版本标记、同专辑歧义与候选上限 | 未验证 |
| 纯音乐 | 继承 LRCLIB instrumental 标记过滤，不伪造时间轴；未知原生结构保留 | 真实纯音乐 UI 未验证 |
| 中文 / 英文 / 日文 / 韩文 | 元数据匹配和原生保留；拒绝无依据的转写/译名 | 未验证 |
| 超时 / HTTP 失败 / 格式异常 | 模拟原生回调错误、503、无效 JSON、压缩原字节和畸形 protobuf、超大正文 | 未验证 |
| 缓存 | 成功 30 天、命中、过期重新取得、更新、来源与修订验证、异常完整记录、容量上限 | 未验证 |
| 逐字 | 原生 JSON 逐字字段保留；独立 wire 字段保留与旧 codec 回归；来源不生成虚构逐字数据 | 原生逐字高亮未验证 |
| 快进 / 后退 / 跳转 | 原时间戳不变、LRC 小数 / offset / 重复时间戳及顺序检查 | 真实播放进度响应未验证 |

Node 的四个回调式客户端模型和 Egern 的 Response/stream 模型是不同适配。VM 能执行说明代码适配与测试夹具一致，不等于客户端官方解析器、Spotify UI 或 HTTPS 中间人链路已通过。

## 性能和边界

沿用本地直到真实 I/O 才异步的构建变换，来源帮助函数按需初始化；默认关闭配色联网和翻译，顺序来源请求；没有后台扫描、跨请求排队或增加并发容量。原生路径测试检查请求次数和单次完成，而不以时间快慢推测手机内存。

歌词正文 256 KiB、入口正文 128 KiB、单个来源一般 96 KiB、累计来源 256 KiB、最多 600 行、最多 12 次来源请求。元数据公开嵌入页沿用独立的 256 KiB 文本读取边界。脚本总体工作窗口 10 秒，原生歌词脚本 timeout 12 秒；单次来源 HTTP 至多 2.5 秒，Loon 用毫秒，Surge 桥接换算为秒。没有发明可取消 Loon HTTP 的能力。

compact 缓存为 64 条 / 32000 字符；standard 为 128 条 / 64000 字符。它们是字符串容量上限，不是系统内存保证。共享存储的网络 lease 只有建议性协作，没有原子 compare-and-swap 保证；不能由模拟调度推导所有进程永远只发一个请求。

历史归档的 Node / macOS JavaScriptCore 测量保留了改善和退化。本轮未重跑整套旧性能测量，也未测量手机 CPU、RSS、峰值内存、耗电或长时间 VPN 稳定性，不能宣称百分比性能提升或断连已经修复。

## 后续设备验收记录

每次记录客户端版本、系统版本、Spotify 版本、来源许可版本、源码/产物哈希、曲目 ID 与已脱敏的响应结构。先验证 Loon：有词逐字节不变、无词歌曲补全、纯音乐/全无词、错误候选拒绝、连续切歌、快进/后退和恢复原生。出现 VPN 断开时取得对应日志，区分宿主终止、内存压力、网络失败和脚本异常。

通过 Loon 后单独做 Surge iOS 与 macOS，再评估其他客户端。没有取得观察证据的单元格继续标为未验证。
