# SpotifyLyrics v3.2.3 — 非中文歌词翻译修复

拟发布说明，当前本地准备完成，尚未推送或发布。基于现有 3.2.2 核心保留协议与缓存身份。

## 修改

- 按用户要求，中文原词保持，其他语言可进入所选目标语言的翻译；取消原先只允许英语整曲的门槛。
- 恢复生成脚本中被英语专用优化裁掉的共享翻译路径，手机与 Mac 歌词使用同一维护源码。
- 中外文混合句保留中文片段；旧缓存 / 来源译文不得悄悄改写中文原词。
- 翻译服务失败或没有有效结果时保留完整原生响应与 Spotify 官方译文。
- 原搜索匹配、来源、参数默认值、时间轴、容量、串行请求、期限和 Mac 请求 / 入口适配保留。

## 验证

- 独立构建：626 项 Node / 18 项 Python 通过，包含 235 项新增策略与完整脚本测试。
- 当前源码兼容检查：1011 项执行通过；8 项与新要求相反的历史政策断言按精确名称排除，新规则由新增测试覆盖。
- 未修改的历史基线：2248 项全部通过；原测试桥 72 项匹配。
- 现有翻译服务对自写日文 / 英文测试句返回 HTTP 200 与可用中文译文。
- 桌面 JSC：80 进程 / 840 次调用，峰值 footprint 13189744 字节、resident 18448384 字节；单并发、合成网络，不能代替 iPhone 50 MB 实机验收。

## 安装与边界

更新独立仓库的新订阅入口后，才会取得本修复的固定运行资源。旧 Proxy 订阅不会自动切换。

用户反馈的 First Love 与 BLACKPINK 现场串烧已核对公开元数据，并用这两个公开路由及自写歌词测试。未获取这两首歌真实客户端歌词响应，原生显示仍待验证。

Mac 无词入口、真实逐字译文显示、iPhone 代理扩展 50 MB 与长期稳定验收仍未完成；本版不伪造逐字时间戳。当前没有更新任何已安装客户端或 VPN，也没有播放音乐。
