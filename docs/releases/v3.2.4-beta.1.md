# SpotifyLyrics v3.2.4-beta.1 · iPhone 启动内存测试版

这是 Pre-release，用于验证“iPhone 打开 Spotify、开始播放即导致 Loon VPN 断开”的修补。**实际断线修复和 iPhone 整个 VPN 扩展严格低于 50,000,000 字节仍未验收通过。** 正式版继续为 v3.2.3，main 不切换到本测试版本。

使用测试订阅替换现有 SpotifyLyrics 那一份，保留原设置，并保持只启用一份 SpotifyLyrics。iPhone 的运行平台保持 `mobile`；Mac 选择 `macOS`。刷新 main 或旧 Proxy 链接不会取得这个测试版。此次发布不自动修改任何客户端或 VPN 配置。

更新后，重新打开 Spotify 并开始播放，检查 Loon VPN 是否仍会断开。若仍失败，需要记录发生时间、Loon 错误文字及手机/iOS/Loon/Spotify 版本，以继续区分原生内存退出与其他隧道错误；不能用 Mac 的数值代替手机验收。

回退正式版时，将这一份 SpotifyLyrics 的订阅改回 [main 正式订阅](https://raw.githubusercontent.com/hhhoratioxu/SpotifyLyrics/main/Loon/script/SpotifyLyrics.lpx)。

## 本次修补

- 手机入口跳过原核心明确只会透传的 metadata/extended-metadata/bootstrap/customize JSON，减少无用的 Body Script 执行；已支持的播放器 JSON、二进制和缺失类型路线保留。
- 忙碌且没有可用缓存时，在解码正文前保留原状态、原词与官方译文。原生歌词包也在完整核心初始化前做同步检查，减少冷竞争回应的物件建立。
- 完整/部分整曲译文、旧逐行缓存、同曲补词缓存及原设置继续使用；旧 HTTP 回调必须真实结算，禁止通过提前完成掩盖未结束的网络工作。

六源补词、匹配规则、时间轴、缓存容量/TTL 和“中文原词保持，其他语言进入翻译”策略保留。核心协议标记仍为 3.2.2，以维持兼容；分发测试版版本号为 v3.2.4-beta.1。

## 验证与限制

独立临时目录、无 Git 数据库、重新安装锁定依赖后的构建通过：678 项 Node、18 项 Python、1011 项当前核心兼容、2248 项原始历史基线及 72 项内存测试桥。新增检查共 52 项；最终导入信息更新后另有 31 项安装链检查通过。

桌面压力模型每个版本、每种回收方式各 96 个进程/696 次执行。保守延迟回收模型的最大 footprint/resident 从正式版的约 59.62/78.66 MB 降至约 50.46/62.62 MB，**仍超出 50 MB**。及时释放模型约 13.11/19.04 MB，但不能选择这一较低值声称手机已经通过。测量不含 iOS 扩展、真实 HTTP/TLS 缓冲或其他插件。

本次没有播放音乐、操作客户端界面或修改其他项目。手机/Surge/Egern/Quantumult X/Shadowrocket 的实机结论不因打包而改变；Mac 无词入口与精确同步的既有未验收状态保留。
