# 非中文歌词翻译修复

状态：v3.2.3 已推送并公开发布，Latest 与全部公开下载已核对。详见 [发布校验](../evidence/release-v3.2.3.json)。v3.2.2 固定迁移版保留旧策略，持续更新请使用新仓库 main 订阅。用户于 2026-11-15 确认 push；本次不更新已安装客户端、VPN 或用户缓存。

## 用户要求与旧行为

用户反馈两个公开曲目没有翻译，随后明确要求“除了中文都要翻译”。公开曲目元数据核对为：

- [First Love](https://open.spotify.com/track/39HrUxcvKF3jtLz7fUDWXc)，宇多田光，专辑 First Love，257293 ms。
- [ラスト・クリスマス 〜 赤鼻のトナカイ - BLACKPINK ARENA TOUR 2018 "SPECIAL FINAL IN KYOCERA DOME OSAKA"](https://open.spotify.com/track/6149wOhItvVX0zoa1KK5hw)，BLACKPINK，现场专辑同名，232566 ms。

旧 3.2.2 对中文目标采用整曲英语门槛，日文、韩文等会被跳过。其构建又删除了该门槛下不可达的多语言 / 中文片段处理。此次按新要求同时调整维护源码和构建，保留历史原件与原有低层译文处理，没有改动搜索匹配或加入按曲目 ID 的特例。

## 新行为

- 中文原词保持，包括简繁体及中文目标以外的设置，不因翻译服务返回另一种写法而互转。
- 日语、韩语、法语、德语、西语、俄语、阿语、泰语等非中文内容均可进入原翻译服务；未标记语言使用原有自动识别路径，不再要求英语词汇证据。
- 中外文混合句沿用已存在的片段翻译，保留原中文片段。旧快取或来源译文若改写中文片段，会重新请求外文部分。
- 日本汉字与韩文汉字使用已有源语言标签消歧。缺少可靠语言标签的纯汉字词保留，不根据歌名、艺人或语言猜测内容。
- 网易 / QQ 同次响应中精确对齐、符合目标的译文继续复用；不按近似行号、错位时间或错误歌曲复用。
- 译文服务失败、格式错误或没有可用结果时，保留原始响应及 Spotify 原生译文。部分成功仍按原行数输出，原歌词、时间戳和已有逐字信息保持。
- 64 行 / 6800 字符 URL、96 KiB 服务响应、600 行、60000 译文字符与原有串行请求、期限、缓存容量继续生效。保持现有服务与 source-language 行为，不引入每种语言的额外轮询。

Mac 歌词核心与手机使用同一维护源码。旧请求 / 入口适配保留，JSON 显示包装只对既有逐行 / 静态兼容格式拼接译文；有真实逐字 / 音节时不破坏时间关系，不伪造逐字时间戳。
